# Todo API Backend

This is a FastAPI backend for managing todos with user authentication.

## Endpoints

- `GET /` - Health check
- `/api/{user_id}/` - Task endpoints
- `/auth/` - Authentication endpoints

## Technologies Used

- FastAPI
- SQLModel
- Uvicorn

## Configuration

The API is configured to run on port 8000 and is accessible via the Hugging Face Space container.
